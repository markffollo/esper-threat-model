Architecture & Summary

Blueprint
What StealthIt is, how it is built, and where the trust boundaries sit.

The repo ships two versions of the same app: an original build (antigravity-original) and a newer, more polished rebuild (claude-opus-5) that the project recommends. Both are the same idea — a floating AI assistant that stays invisible on video calls. The newer version stores your AI account keys encrypted and keeps recordings of your meetings; the original stores keys in a plain text file and has no history at all. We reviewed both:

Original versionNewer version (recommended)
Where your AI account keys are keptPlain text file — anyone on the PC can read themEncrypted, tied to your Windows account
Which AI services it talks toGoogle, Anthropic, OpenAI, local OllamaAll of those + OpenRouter & Cerebras; server address is user-changeable
Meeting historyNot saved at allSaved as unencrypted text files
ExtrasBasic interfaceOffline transcription & screen reading

Data at risk — the sensitive data that moves through the app, in plain words

  • Full screenshots (could include dashboards, credentials)
  • Meeting audio → local transcripts → cloud prompts
  • Provider API keys (Bearer) sent to any configured host

Attack paths (Critical / High) — plain-English chains: attacker action → exploit → access → impact

  • F3+F4 — plaintext .env read / tampered base_url → Bearer key sent to attacker's http:// endpoint
